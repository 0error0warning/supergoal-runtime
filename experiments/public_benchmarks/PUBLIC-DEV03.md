# public-dev03：移除容器初始化中的 Python 前置依赖

继承 public-dev02 的六个任务、五组、运行顺序和全部预算。public-dev02 没有进入模型比较：HTTPS 参考解预检中前四个任务通过，`configure-git-webserver` 的原始 Ubuntu 镜像没有 Python，初始化脚本因此失败。失败记录及原候选归档保留。

本版本只把 Debian APT 的 HTTPS 替换改为容器已有的 POSIX shell、sed 和 sha256sum，宿主 Python 解析散列回执。不额外安装 Python，不修改任务、参考解或官方 tests，也不改执行器/审查器提示、预算和停止规则。Ubuntu 镜像不包含待替换的 Debian 源时，初始化为空操作。

先用真实 Hermes 的无模型工具 smoke 检查 Ubuntu 镜像上的终端/文件读写，再运行六个官方参考解。所有门槛通过后才开始模型比较。源码、任务树、镜像和操作脚本分别冻结；每个正式试次前复核。评分前快照和已结束容器继续保留。文件、终端工具因任务内缺少额外程序发生的问题保留在模型轨迹中，不私自为某一组补装依赖。

模型流量使用已验证的腾讯云 → grok-bot Tailscale 直连，本机无需在线。此项是实验运行条件，不能当作跨天自治或中断恢复成绩。在线审查器仍未完成全局校准，本轮数据仍为开发数据。
