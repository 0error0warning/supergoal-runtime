# public-dev02：环境修正后的公开任务开发试验

继承 `PUBLIC-DEV01.md` 的任务、五组比较、96 次实际上游请求预算和官方时间/CPU/内存限额。仍为开发试验，不作优越性或跨天自治结论。

变更原因：public-dev01 首个 native 试次真实调用 SWE2 三次、生成产物并自检，但官方评分器下载 Debian 依赖时返回 HTTP 500，未运行测试便写出 reward 0。该原始零分保留并标为评分装置失败。Harbor 的 `delete=false` 仍会移除容器，故无法直接复评原始文件系统；不得把重建产物当成原始现场。

本版在所有分组启动前统一把容器内 Debian APT 源的 `http://deb.debian.org` 换为 `https://deb.debian.org`，记录修改前后散列。保持 TLS、包签名、原始任务 instruction、参考解和隐藏 tests 不变。这是已公开的依赖传输适配；不是严格零改动的原始镜像环境。

所有试次在最终隐藏评分开始前保存任务文件系统 Docker snapshot，报告不可包含挂载日志的边界。Harbor 保留自己的日志/产物；开发阶段同时保留停止的容器，便于评分失败后的独立复评。复评不再次调用模型，原始结果不覆盖。

在线审查器若没有任何工具观察，不能以自由文本宣告 pass。此检查只排除一种明显的无证据通过，不代表 LLM 审查已校准或语义正确。该研究适配器使用真实 v2 内核，但仍不同于日常网关插件的脚本验收。

新登记文件和源码归档与 public-dev01 分开。旧试次不计入本版的配对效果估计；版本变化不是新的随机种子。

## 执行环境与复现

模型调用已经改为腾讯云 Hermes 主机直接经 Tailscale SSH 转发到 grok-bot 的本地监听端口。关闭 Windows 上的两个转发进程后，认证模型列表请求仍返回 200；无需本机保持在线。隧道断开后重新连接仍可能触发 Tailscale 身份复核，该依赖不等于已经证明了跨天故障恢复。

[环境锁文件](environment-public-dev02.json) 在本候选首次模型调用之前记录六个官方任务的完整文件散列、镜像 ID 和可用的 registry digest。研究执行器在每个试次前再次核验。模型看不到这些官方参考解或最终 tests；目录散列只用于宿主复现检查。

[串行执行器](run_registered.py) 只执行预登记行，整个研究共六个不同 task ID、五组、每个组合一次。每次运行至少保留 4.5 GiB 可用宿主内存和 15 GiB 空闲磁盘；不足时停止等待审计，不给任务降配。装置失败不会自动增加种子或覆盖已有行。官方参考解的 HTTPS 预检见 [operator 入口](oracle_preflight.py)，零模型调用，不能算作 Supergoal 完成任务的成绩。

候选代码固定于 `experiments/baselines/sg-public-dev02.tar.gz`；操作脚本单独记录散列，不在模型执行环境内。开发阶段保留评分前镜像、停止后的容器、官方评分原始日志和宿主控制记录。
