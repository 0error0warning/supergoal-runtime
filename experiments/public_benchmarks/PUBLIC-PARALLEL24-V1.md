## 冻结与验收

候选 public-dev05 的散列见 [登记](registration-public-parallel24-v1.json)，本地字节快照见 [归档](../baselines/sg-public-dev05.tar.gz)。正式题目结果出现后不再修改该候选。参考解只用于环境验收，评分器和参考答案不进入求解器容器、提示或在线审查。参考解失败的任务保留原始分数和日志，并将五个模型组均标为环境不可用，不计作模型零分。

## 分析

以 task ID 为统计单位，主要比较完整 v2 与原生 Hermes；报告双向不一致成功数、精确 McNemar 检验和任务级 bootstrap 差值区间。bootstrap 只重采样已有数据，不增加模型试次；小样本或差值相同会形成退化区间，不是总体能力保证。重发目标和两个消融为探索性次要比较。另报请求量、时间、错误接受、控制器失败、未完成配对和环境缺失。

原始官方分数不覆盖。评分装置失败与求解器失败分列；控制器失败同时计入端到端指标。所有旧失败、校准尝试和版本均保留。

公开题目可能出现在预训练数据中。任务时限或人类工作量标签不等于实际自主运行时长；本批不能单独证明跨天自治、生产插件端到端能力或任意任务通用性。
