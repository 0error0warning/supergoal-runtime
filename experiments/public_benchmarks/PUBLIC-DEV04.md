# public-dev04：公开任务比较的当前冻结候选

任务、分组、顺序、提示、预算及停止规则继承 public-dev03。该候选另外处理 Harbor 将没有标准输出的成功命令表示为 `stdout=None` 的接口行为。没有待替换 APT 源时必须记为空变更，不能把它当作任务失败。public-dev02/03 都没有模型比较试次；参考解和初始化失败记录分别保留，不加入模型成功率分母。

环境适配仅为 Debian APT HTTP → HTTPS，使用镜像已有的 shell 工具；不额外安装 Python、不改官方任务/参考解/tests。真实 Hermes 已在不含 Python 的原始 Ubuntu 镜像通过终端、文件写入/读取、宿主路径不可见和执行超时检查，模型请求为零。

每试次同为 96 个实际上游 SWE2 请求、最多 6 个执行轮次、每请求 6000 输出 tokens，全部审查和重试共享官方任务墙钟预算。六个不同 task ID、五组、每个组合一次，串行运行。请求数与时间上限相同不代表各组实际 tokens 相同；总输入 tokens 未设硬上限，报告实测成本。

日常网关插件与此研究入口仍须区分：此入口调用真实 Hermes SDK 和 v2 SQLite 内核，但在线 LLM 审查不是日常插件的已校准脚本验收。审查使用文件系统快照，快照不保留原容器的运行中进程；对依赖服务运行状态的要求可能证据不足。这个局限必须计入审查误判与拒绝判断的分析，不能把快照审查通过等同于官方通过。

评分前保存文件系统镜像，官方评分在执行器退出之后进行；隐藏 tests 不反馈给模型。原始分数、评分日志、全部版本的装置错误和独立模型请求收据保留。最终输出只代表公开开发样本，不是尚未观察过的保留集，也不能单凭这些短任务证明跨天自治。

详见对应 `registration-public-dev04.json`、`environment-public-dev04.json` 和 `experiments/baselines/sg-public-dev04.tar.gz`。模型连接已独立于 Windows 本机，经过腾讯云 → grok-bot 的 Tailscale SSH 隧道；重新建立连接可能仍需身份复核。
