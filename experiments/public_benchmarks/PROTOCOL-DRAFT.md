# 公开任务研究协议草案

状态：这是研究总协议。当前模型比较候选是 [public-dev04](PUBLIC-DEV04.md)，旧候选与装置错误保留。实际执行以对应登记文件、源码归档和[结果收据](../../docs/public-benchmark-study-2026-10-05.md)为准。正式保留集仍须在开发结束后另行冻结；本文件不是已完成的实验结果。

## 目标与解释单位

研究有限目标在相同模型、工具、任务环境和总资源上限下的独立验收完成率、未达标便停止、错误宣告成功、有效执行时间及恢复表现。目标可以经历多轮实际工作；等待时间单独记录。每个官方 task ID 是任务单位，重复采样不算新的任务。上一轮合成任务及其随机变体不并入公开基准成绩。

## 分阶段评测

实际服务器为 `grok-bot`，8 核 / 16 GB，经 Tailscale SSH 接入；禁用本机 Docker。采用并发 1、按需镜像缓存，先预检官方声明 1 CPU / 2048 MB 的任务。共有 68 个这样的任务；资源资格不等于已通过环境检查。保持每个入选任务原有资源限额和评分流程，不为塞进小机器而降配后仍称原样复现。GUI 环境另行评估，不作为 CLI 实验的前置要求。完整元数据目录和排除原因见 `terminal-bench-2-1-catalog.json`。

1. **Terminal-Bench 2.1**：先验证 CPU 可执行任务的官方环境和 oracle。按元数据中的任务类别及资源需求分层选择不同 task ID；公开选择规则和全部排除原因。不按 Supergoal 的表现选题。正式任务使用原始 instruction、初始镜像和最终 verifier；solver/参考实现/隐藏 tests 不进入执行器。
2. **AgentIF-OneDay**：使用官方完整 description 和任务附件，冻结来源数据。`score_criteria`、reference answer 和答案附件只交给最终评分器。按实际文件内容评分，不能只看模型说做过什么。先验证 LibreOffice/浏览器/媒体工具和附件解析。
3. **WeaveBench / OSWorld**：先核验 KVM、发行版一致性、GUI 工具、截图输入以及必要的数据访问权限；将 Hermes 接到环境工具接口，不能以纯文件改写冒充受 GUI 限制的原始任务。先做不计成绩的装置 smoke，再冻结正式选择。

已阅读过的 AgentIF `taskif_1` 用作数据格式/规则审计样本；不作为未经观察的保留任务。发现其请求文件名与 rubric 文件名存在不一致时应记录，不静默改官方题目或 rubric。

## 对照、预算与隔离

比较原生 Hermes、仅重发原始目标的简单续跑、完整 Supergoal，以及分别移除状态补充、运行时验收/审查的消融。原生 Hermes 单次执行允许使用完整预算，不能故意设很小的轮数让它先失败。各组的工具、输入、可见信息和总模型请求、时间及每请求输出上限一致；所有判断、重试和辅助模型调用都计入预算。public-dev01/02 限制每试次 96 个实际上游请求，每请求最多 6000 输出 tokens；总输入 tokens 记录实测值，尚未设置硬上限。

隐藏最终评分器不得成为续跑反馈。运行时检查只能使用任务已公开的要求与工具可见信息；如果增加官方任务没有提供的检查/信息，必须明确标为适配设置，另行报告。移除审查的实验只能在无生产权限的隔离任务环境中进行。

真实中断恢复作为独立实验，所有组接受相同的中断安排；正常任务的完成率与故障注入成绩分开。保存任务环境和待办的简单恢复基线是必需的，不能仅与无法恢复的单进程比较。

模型使用 `devin/swe-2`，记录请求/响应实际别名、调用用量、上下文策略和工具版本。GUI 任务先验证该端点的图像输入能力。AgentIF 官方已报告分数采用不同 judge；如果本研究仍用 SWE2 评分，应标明 judge 改动，并抽样人工核对。不能把这个分数直接放进原论文表格充当同设置复现。

## 数据与分析

预先登记具体 task ID、分组顺序、重复次数、每任务资源上限、排除条件、停止规则和计划比较。所有失败和装置错误保留；环境失败独立分类。修改内核/提示/验收后使用新的候选和实验编号，旧试次不覆盖。

以官方任务为配对/聚类单位报告差值和置信区间；不同基准分别报告，不把所有分数直接平均。重复和随机种子不提升领域多样性。没有足够差异时明确报告证据不足；不把全通过解释为等效，也不把一次长时间等待称为长时间独立推理。

最终结果应包含任务级得分、最终产物、原始执行轨迹、模型调用收据、实际工作/等待时间、验收争议率、检查器误判及其人工审计。通用性结论只覆盖实际执行的任务和环境。
